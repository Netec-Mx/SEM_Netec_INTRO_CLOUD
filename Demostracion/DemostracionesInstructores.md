# Demostración para Instructores - Introducción a la Nube: Conceptos, beneficios y panorama de AWS y Azure

El propósito de este documento es sugerir la demostración que el instructor puede realizar durante la entrega del seminario Introducción a la Nube. Los siguientes pasos son generales, se entiende que el instructor tiene las habilidades para comprenderlo. Están organizados en orden de los slides de Power Point adjuntos. 

## Ejemplos cotidianos
- Mostrar ejemplos cotidianos del uso de la nube: Sistema de archivos, correo, reuniones, plataformas de streaming, apps móviles, IA.

## De guardar y trabajar “en mi equipo” a acceder a servicios desde cualquier lugar
- Muestra rápidamente la sincronización y acceso desde otro equipo (VM) con OneDrive, o podría ser con servicios de archivos como Azure FileShare o amazon EFS.

## Modelos de nube
- Mostrar un ejemplo de cada modelo preparado previamente sin profundizar el la parte técnica. Por ejemplo: VM, Azure SQL Database o RDS y OneDrive.

## Agilidad y escalabilidad
- En un grupo de autoescalamiento o VMSS eliminar una máquina para ver el escalamiento en acción.

## Disponibilidad y continuidad
- Cambiar de tipo de redundancia en un azure storage account de LRS a GRS y ver gráficamente su redundancia. 

## Consumo y costo
- Usa la calculadora de costos de Azure o AWS.

## Total Cost Owner(TCO)
- Ingresar a la calculadora de costos totales de Azure (si no está disponible omitir[Se depreció en 2025, pero es una excelente forma de mostrar qué hace una TCO calculator])

## Amazon Web Services (AWS)
- Ingresar a la consola y mostrar todos los servicios disponibles, además, mostrar la infraestructura global desde la herramienta oficial.

## Microsoft Azure
- Ingresar al portal y mostrar todos los servicios disponibles, además, mostrar la infraestructura global desde la herramienta oficial.
